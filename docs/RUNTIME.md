# Runtime adapter contract — not an implemented generic connector

Input: trusted Gmail connector raw RFC2822/base64url, immutable message ID, stable per-mailbox alias and receiver timestamp. Never thread ID or model-authored auth_pass. Deterministic parsing must enforce receiver boundary, sender alignment, MIME decoding, multiple-DKIM policy and reject unknown/failure. Keep raw local/ephemeral; do not transmit it to GAS or source control.

Read the complete versioned ledger including dynamic columns and request/run journals. Read revision before/after; retry reads if changed. Preserve JSON null vs zero vs missing. Link notices/CSV only when uniquely supported; ambiguous duplicate matches remain held and never become duplicate expenses. Rejected/authorization-only notices remain excluded or provisional as defined by the parser, not confirmed bills.

The classification model operates on sanitized evidence. User decisions/locks take precedence. No purchased item invention. Source inventory must mechanically match verified Gmail reads; details/classification cannot reuse a source across unrelated purchase roots. Preserve manual notes, legacy evidence, details run immutability and exact run replay.

Output: a validated immutable schema exchange plus its expected before/after invariants, written only to the user's preconfigured private inbox. GAS must validate configured ownership and private file/folder access, size/schema/capability, source inventory, revision, request/run digests and atomic commit. Owner-only UI access and private underlying file ACLs are separate requirements; never infer one from the other. A connector must not write Sheets directly. Required Drive write permission belongs only to the orchestrator; GAS uses Drive read-only. No new credentials are provided by this repository.

Completion requires the GAS receipt, actual runtime observed-clock guard, full readback and confirmation. `observed_at` must come from Date.now() in trusted executable code, never model input. Enforce generated_at <= receipt commit <= actual observed time; validate target updated_at/details timestamps; reject future/invalid times. The public `python3 worker/cloud_entry.py confirm` entry point includes `tools/observed_clock_guard.cjs` and obtains time in executable code. The internal confirmation helper alone is not a completion check. Retain the unmodified validate output and a complete fresh readback; do not replace either with a model-authored summary.

This candidate integrates the fixed source-evidence and full-row confirmation implementation with a public clock-guarded CLI. This is a separate release candidate, not a claim that an existing deployment has changed. Regenerate and verify the candidate manifest after source changes. The offline tests do not demonstrate general connector transport, OAuth or scheduled operation.

`SCHEMAS.json` is descriptive contract metadata, NOT a standard JSON Schema. Public adapter must run Python validate before transport; legacy schema1 matched classification has a compatibility path without source inventory. Never standardize direct arbitrary model JSON into GAS. The source-evidence multiple-DKIM policy and card decoder policy differ; do not advertise them as interchangeable. Core CSV staging also needs the full app Csv13Import module.
